IMPLEMENTATION PLAN
AI-Powered Lead Generation & Outreach Tool
===========================================

Building an AI-powered lead generation and outreach tool is an excellent project. By combining
modern web frameworks with AI's ability to parse unstructured web data, you can build a system
that replaces hours of manual research. Here is a comprehensive blueprint to architect and build
this system.


RECOMMENDED TECH STACK
-----------------------
- Frontend:    Next.js (React) with Tailwind CSS
               Provides a fast, responsive UI -- perfect for data-heavy dashboards and data grids.

- Backend:     Python (FastAPI)
               Python is the industry standard for AI, web scraping, and data manipulation.
               FastAPI is incredibly fast and built for the asynchronous operations you'll need
               for network requests.

- AI Engine:   Google Gemini API
               With its massive context window and native support for structured JSON output via
               Pydantic, Gemini is ideal for extracting clean data from messy, unstructured
               website text.

- Data Gathering:
               Playwright (for rendering dynamic web pages) OR dedicated enrichment APIs
               (e.g., Hunter.io or Apollo) to ensure you are pulling high-quality, verified emails.

- Outreach & I/O:
               SendGrid for scalable email delivery and the Google Sheets API (via the gspread
               library) for seamless list exporting.


SYSTEM ARCHITECTURE
-------------------
1. Input:      The user submits their target criteria (e.g., "Boutique marketing agencies in
               Austin") via the Next.js frontend.

2. Gathering:  The FastAPI backend receives the criteria and triggers a web scraper or calls an
               enrichment API to gather raw HTML and unstructured text.

3. AI Parsing & Enrichment:
               The raw data is sent to the Gemini API along with a strict Pydantic model defining
               a Lead. Gemini parses the text, extracts the relevant fields, and returns a
               perfectly formatted JSON array.

4. Review:     The frontend fetches the structured JSON and renders it in a templated UI grid.

5. Action:     The user selects specific leads to either trigger the SendGrid API for personalized
               outreach or the Google Sheets API to export the compiled list.


IMPLEMENTATION GUIDE
--------------------

Step 1 -- Set Up the Backend and Data Models
   Define the structure of a lead.
   Initialize a FastAPI project and define exactly what a lead looks like using Pydantic. This
   schema will be used by both your backend validation and the Gemini API to guarantee structured,
   predictable outputs.

   from pydantic import BaseModel, Field

   class Lead(BaseModel):
       company_name: str = Field(description="The name of the business")
       email: str = Field(description="Verified contact email")
       industry: str
       decision_maker: str = Field(default="Unknown")
       website: str

Step 2 -- Build the Scraping & Enrichment Engine
   Implement the logic to gather data. To avoid IP bans and CAPTCHAs, it is highly recommended
   to integrate a B2B API like Apollo or Hunter for the heavy lifting. If you are custom scraping,
   use Python's Playwright to load pages dynamically and extract the text content of the page.

Step 3 -- Integrate Gemini for Parsing
   Pass the raw, unstructured text to the Gemini API. By passing your Pydantic Lead model to the
   SDK, you force the LLM to filter the noise and output a clean JSON array that perfectly matches
   your frontend's expectations, eliminating the need for complex Regex or HTML parsing.

Step 4 -- Develop the Frontend Dashboard
   Build your Next.js UI using a robust data grid component (e.g., AG Grid or MUI DataGrid).
   Ensure each row has a checkbox for selection, and add global action buttons for "Send Email"
   and "Export to Sheets" at the top of the dashboard.

Step 5 -- Wire Up Actions (Email & Export)
   Create API routes in FastAPI that accept an array of selected leads.

   For emails:
     Loop through the array and hit the SendGrid API with your HTML email template.
     Use a background task for this so the user does not have to wait for the HTTP request
     to finish.

   For exporting:
     Authenticate a Google Cloud Service Account and use the gspread library to append the
     selected leads as new rows in a target Google Sheet.


API INTEGRATIONS & BEST PRACTICES
----------------------------------

Email Integration (SendGrid)
  - Authentication:
    You must authenticate your sending domain (SPF, DKIM, DMARC) before sending a single email.
    If you skip this, major email providers will instantly route your messages to the spam folder.

  - Asynchronous Processing:
    Use a queuing system like Celery, Redis, or FastAPI's BackgroundTasks for bulk sending.
    Sending 500 emails in a synchronous loop will cause your backend request to time out.

Google Sheets API
  - Create a project in the Google Cloud Console and enable the Google Sheets API.
  - Generate a Service Account JSON key.
  - CRUCIAL: Manually share the target Google Sheet with the Service Account's generated email
    address to grant the bot write access.

Compliance & Deliverability
  - CAN-SPAM (US):
    You are legally required to include a valid physical postal address and a clear, conspicuous
    way for the recipient to opt-out (an unsubscribe link) in every commercial email.

  - GDPR (EU):
    B2B cold outreach is generally permissible under "legitimate interest," but you must only
    contact corporate email addresses (e.g., alex@company.com), never personal ones
    (e.g., alex123@gmail.com).

  - Warm-up:
    Never send a massive blast from a new domain on day one. Gradually increase your sending
    volume over several weeks to build a positive sender reputation.
